# PXL Seq website

Public product page for PXL Seq by Pixel Records.

Live URL: https://tomislavrupic.github.io/PXL-Seq/

Buildless static HTML, CSS and JavaScript. GitHub Pages serves the repository root.
No analytics, external fonts, cookies or build dependencies.

This repository contains the product website and actual interface screenshots,
not plugin source or binaries. Public plugin downloads are available as signed and notarized AU/VST3 packages.

The phrase visualization is silent and illustrative, not the plugin engine.
The page labels this beside the preview and shows download availability
near the top. Instrument, Setup and Release links remain available on mobile.

The 0.5.0 images show the native Performance and Edit views and a desktop WebKit
capture of the Safari controller connected to the installed AU. The controller
image shows the iPad layout, not an actual iPad hardware capture. No pairing
codes, private endpoint URLs, plugin binaries or native source are included.

Creator: https://tomislav-rupic.com/
